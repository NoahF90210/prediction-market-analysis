# Legacy Results Quarantine

The previously committed dashboard payload and its numerical claims are not part of the rebuilt evidence chain.

They are not copied into the new protocol, fixtures, derived artifacts, README claims, or dashboard payload. They remain recoverable from git history only for forensic comparison.

Do not use the legacy payload to:

- seed probabilities or outcomes;
- choose event groups;
- fill missing snapshots;
- validate platform metrics;
- write portfolio or résumé claims.

The rebuild may reuse transport utilities, basic metric formulas, category-taxonomy machinery, tests, and the static dashboard shell only where each component passes the new contracts.
